# 《一笑江湖 · 天上白玉京》制作复盘

## 1. 这次做对了什么

### 先定“情绪母题”，再定画面

用户给的关键信息只有两个：歌很悲凉、想要“天上白玉京”的清冷仙山。于是把视觉母题定成：

> 天庭不是仙境，是一座华美的囚笼。

所有镜头都围绕这一句做减法：白玉宫殿、空殿、冷月、霜树、无人宴席、破镜、云海、人间灯火。没有打斗大场面，唯一的热色是“回忆里的天宫宴”和“黄沙战场”，用暖色作对比，冷色才更冷。

### 三类素材各司其职

1. **AI 插画**：承担人物、宫殿、云海、战场等“实拍感”镜头，Ken Burns 慢推。
2. **程序化天气**：雪、雾、雨、gate weave、颗粒、暗角，统一全片质感，成本极低。
3. **排版型“玉牒”**：不依赖网页，直接用 Pillow 画深色玉牒、竖排大字和朱砂印，作为间奏的视觉换气口。

这套结构比纯 AI 图堆叠更像“MV”，也比纯程序化更有细节。

### 调色用矩阵，不靠逐张凭感觉

把全片归到 5 个 tint：

| tint | 用途 | 处理 |
|---|---|---|
| cold | 天庭现实 | 青灰、降饱和、抬蓝阴影 |
| memory | 天宫宴回忆 | 暖金、低对比、过曝、强 bloom |
| red | 黄沙战场 | 暗红、高对比、压低绿色 |
| warm | 人间灯街 | 琥珀、暖高光 |
| dawn | 结尾云海 | 淡金、低对比、轻 bloom |

同一张图换 tint 就能复用成“回忆/现实”，这是这次最省成本的技巧。

## 2. 踩过的坑

### 抖音音轨拿不到

- `yt-dlp` 解析到视频 id，但抖音返回 403，要求 fresh cookies。
- 第三方解析接口（tikwm、douyin.wtf）也不可用。
- 最终走网易云公开音源：搜索到原唱（闻人听書_，208.94 秒），用聚合 API 拿到 FLAC 直链，`ffmpeg` 截前 91 秒。

**结论**：抖音视频优先尝试“下载视频→ffmpeg 分离音轨”；失败时不要死磕，直接换网易云/B站公开音源，效率更高。

### 竖排歌词的“孤字列”

最初按每列 8 字切分，9 字歌词会变成“8+1”，第二列只有一个字挂在顶部，读起来像错字。改为：

- 单列最多 12 字；
- 超过 12 字或原文有空格，才分列；
- 分列从右往左读。

9 字歌词（“只身走过多少的岁月”）现在单列到底，干净很多。

### 生成图水印

AI 图右下角有“AI生成”水印。裁掉底部 9% 后再 cover 到 16:9，既能去掉水印，又不破坏构图。

### 回忆段过曝

暖金回忆一开始 bloom 0.55 + lift 0.045，人物脸部细节全糊。降到 bloom 0.40、保留亮部层次，才有“记得但记不清”的感觉，而不是单纯白屏。

## 3. 可复用的流水线

1. **音乐分析**：定歌、截取情绪最完整的 60–90 秒、生成歌词时间轴。
2. **写一句视觉概念**：必须能用一句话说完，例如“天庭是华美的囚笼”。
3. **列镜头表**：按歌词句切镜头，每镜 3–6 秒，标 asset / 运镜 / tint / 天气 / 转场。
4. **生成素材**：统一角色描述、统一画风关键词、统一 16:9；每张图都加“无文字无水印”。
5. **先渲关键帧**：每个镜头抽 1 帧，检查构图、字压脸、亮度、水印。
6. **全量渲染**：Pillow 逐帧 JPEG q92，确定性随机保证可重渲。
7. **编码**：H.264 CRF22 + AAC 192k + faststart；另出 540p 预览。
8. **抽检成片**：片头、第一次转场、歌词最密处、片尾题字。
9. **归档**：timeline / lyrics / 渲染器 / 复盘一起提交，素材和帧走 gitignore。

## 5. 下次可以更好的地方

- 人物一致性仍靠 prompt 约束，特写和全景的脸不完全像；下次可以固定一张角色参考图做 img2img。
- 天庭建筑在多个镜头里细节不一致；可以先生成一张“设定图”，再用它做参考。
- 歌词竖排对不熟悉繁体/书法的观众有阅读门槛，底部字幕这次保留是正确的。
- 转场以 dissolve 为主，下次可以加“墨迹晕开”“云海推入”两种更有国风的转场。
