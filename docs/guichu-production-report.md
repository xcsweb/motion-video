## 0. 结论先行

这一版不再「先排镜头、再配人声」。参考片真正的做法是：

1. **先定 105.47 BPM 的网格**，全片 67 小节，1 小节 2.2755 秒，1 个 16 分音符 142 ms，1 个 32 分音符 71 ms。
2. **先把一句话切成颗粒**。一句 7 个字占 2 小节（32 个 16 分格），每个字被反复触发 4 次左右，落在 16 分/32 分网格上。人声起音密度 6.3 次/秒，31–40 秒段落用更细的检测是 13.3 次/秒，相邻起音中位数 70 ms（≈1 个 32 分音符）。
3. **人声不是「唱准」，是「砸准」**。音高中心是 G，G4 被反复锤；音准只有 35.7% 的帧在 ±15 音分内，颤音 44 音分/7.69 Hz，动态只有 6.5 dB——大量压缩、叠层、限幅。
4. **伴奏是一个双和弦循环**（检测到的强音级是 C、G、D、F、B♭、E♭，低音在 A–C–D 摆动；可简化为 Cm–B♭–F 循环），从头到尾几乎不变。能量不靠起伏，靠**配器密度**：前 8.4 秒没有底鼓，8.4 秒鼓组进，之后 RMS 一直稳定在 −11 至 −13 dB。
5. **画面是「填」进音频块的**。58 个镜头，中位 4 拍（1 小节），81% 的切点落在 16 分网格 60 ms 内（随机基线 42%）。一句词占约 4 小节，这 4 小节里换 8–16 个镜头，字幕却只换一次。
6. **响度是「响度战争」式母带**：整片 −9.41 LUFS，真峰 +0.6 dBTP，LRA 仅 2.1。我们上一版是 −13.83 LUFS，听起来天然「软」4.4 dB。
7. **节奏感来自密度的编排，不是全程快切**：0–8.4 秒只有 2 个镜头；8.4–27.2 秒突然升到 63.8 镜头/分钟；27.2 秒后又落回 20 镜头/分钟。快—慢—快，像鼓组的过门与留白。

上一版失败的核心不是「素材只有《昨天今天明天》」，而是**人声仍是四分音符旋律、镜头密度恒定、没有段落编排、母带偏轻**。这四件事都能在新的制作里修掉。

### 2.2 曲式与段落

### 2.3 和声

- 全片 chroma 的强音级：**C、G、D、F、B♭、E♭**。
- 低音（40–180 Hz）主要在 **A–C–D** 三个音上摆动。
- 人声的音级分布：G 1962 帧、E♭ 1749、F 1370、C 1110。
- 可写作 **C 小调**（C–E♭–G 为骨干），循环用 **Cm–B♭–F–Gm** 四和弦即可覆盖检测到的全部音级。检测器常报 Gm，是因为 G–B♭–D 与 Cm 共享三个音，属于同音级歧义，不影响编曲。

**可复用结论：双和弦/四和弦循环，2 小节换一次，不要写复杂进行。**

### 2.4 配器与频段

每小节能量占比（全片典型值）：

| 频段 | Intro（0–8.4 s） | 鼓组进入后 |
|---|---|---|
| sub 30–90 Hz | 0.04–0.12 | 0.23–0.37 |
| low 90–250 Hz | 0.08–0.35 | 0.10–0.20 |
| mid 250–2k Hz | 0.40–0.64 | 0.40–0.62 |
| high 2k–8k Hz | 0.08–0.23 | 0.03–0.25 |
| air 8k+ | ≈0 | ≈0 |

- **底鼓只在 8.4 秒后出现**，前面靠人声和轻伴奏撑。
- 高频在 12 s、27–33 s 有明显抬升（0.20–0.25），对应 hats/掌声/齿音更密的段落。
- 全片几乎没有 8 kHz 以上空气感，说明是**老素材 + 低通**的味道，不必追求现代高清。

### 2.5 能量与响度

- 8.4 秒之后，每小节 RMS 稳定在 **−11 至 −13 dB**，几乎没有渐强渐弱。
- 5.5–6.5 秒有一个 **−80 dB 的硬静音**，是 drop 前的「抽气」。
- 146 秒开始衰减，151 秒到 −77 dB。
- 整片 **−9.41 LUFS，真峰 +0.60 dBTP，LRA 2.10**。

**可复用结论：不要做大的音量起伏；用「静音 1–2 小节 → 鼓组砸进」制造对比，母带做到 −10 LUFS 左右。**

### 2.6 立体声

中/侧比（side/mid）在 **0.21–0.31** 之间，属于「有人声居中、伴奏略宽」的正常混音，没有夸张的立体声特效。

### 3.2 音符长度

| 指标 | 参考 |
|---|---|
| WORLD 音符段数 | 623 |
| 音符中位时长 | 120 ms |
| 31–40 s 音高平台中位时长 | 50 ms |
| 音高平台密度 | 6.3 次/秒 |

一个 16 分是 142 ms，一个 32 分是 71 ms。**参考的人声颗粒基本就是 16 分/32 分音符，而不是四分音符。**

### 3.3 音高

| 指标 | 参考 |
|---|---|
| 有声帧占比 | 76.5% |
| 中位 F0 | 301.7 Hz（约 D4/E♭4，MIDI 62.5） |
| F0 p10 / p90 | 179.6 / 394.0 Hz |
| 最强音级 | G（1962 帧）> E♭（1749）> F（1370）> C（1110） |
| G4 平台数（31–40 s） | 16 / 57 |

**主音 G 被反复锤**，这是「鬼畜感」的核心：不是旋律写得多花，而是同一个音高被机械地重复，偶尔跳到 E♭/F/C。

### 3.4 16 分落点

全片人声起音在 16 个 16 分格上的强度（归一化）：

```
[0.91, 0.58, 0.67, 0.88, 0.66, 0.72, 0.61, 0.61,
 0.87, 0.97, 0.88, 0.67, 0.89, 0.79, 0.89, 1.00]
```

16 个格子全部有人声，最低 0.58。也就是说：**没有一个 16 分格是空的**。上一版是 `[0.80,0.13,0.41,0.18,...,0.04]`，一半格子接近 0——这就是「念经」和「flow」的差别。

### 3.5 调音特征

| 指标 | 参考 | 含义 |
|---|---|---|
| ±15 音分内的帧 | 35.7% | 音高故意不钉死，保留滑音/颤音 |
| 几乎不动的帧 | 7.4% | 不是完全平直的机器人音 |
| 音内调制 | 15.2 音分 | 每个字内部有轻微起伏 |
| 颤音 | 44.2 音分 / 7.69 Hz | 明显但很快的颤音 |
| 动态范围 | 6.5 dB | 压缩很重 |
| 频谱质心 P95 | 3811 Hz | 保留齿音和辅音瞬态 |

**做法：用 WORLD 保留原始频谱包络（音色/辅音），只改 F0；不要把音高 100% 拉平，保留 20–40% 的原始音高偏移。**

### 3.6 混音链（推断）

从动态 6.5 dB、频谱质心 3811 Hz、立体声宽度 0.25 可推断至少做了：

1. 人声高通（约 100–150 Hz）。
2. 压缩 3:1–6:1，attack 3–10 ms，release 50–80 ms。
3. 人声双击/叠层（左/右或 1/16 延迟），所以听起来「厚」。
4. 轻混响（plate，0.6–1.0 s，湿声 10–15%）。
5. 鼓组侧链压缩伴奏，人声一响伴奏就让。
6. 母线限幅，真峰推到 0 dB 附近。

## 6. 原作者的流程推断

证据链：

1. **切点与 16 分网格对齐 81%**，而人声起音也铺满 16 分格。如果先剪画面再配音乐，很难做到这个比例；只有先有音频网格，再把画面贴上去，才会这么齐。
2. **一句字幕停留 4 小节，但画面在这 4 小节里换 8–16 次**。这说明画面是「素材填充」，不是「叙事剪辑」。
3. **同一镜头/机位被反复使用**（观众席、特写、舞台大全），说明素材是按音频需要去找的，不是按剧情顺序剪的。
4. **多首曲子/多个小品的金句被拼在一起**，但 BPM 和网格完全一致，说明先统一了速度，再做拼贴。
5. **Intro 有 2 小节近乎静音再 drop**，这是音乐编排，不可能是画面剪出来的。

推断流程：

```
选题 → 收集大量素材（多个小品、多个机位、多首歌）
→ 定 BPM / 建小节网格
→ 写词块（一句 7 字，2 小节；4 小节一个段落）
→ 做人声：切片、变调、按 16/32 分重复触发、压缩叠层
→ 做伴奏：双和弦循环 + 鼓组 + 静音/drop
→ 混音母带（−9.4 LUFS）
→ 字幕：一句一块，4 小节
→ 画面：按音频块填镜头，句内切 8–16 个，密度按段落编排
→ 对齐检查（切点/字幕/起音是否同网格）
```

**关键：音频是先完成的，画面是最后一步。**

## 8. 新制作蓝图（音频优先）

### 8.1 总原则

1. **先做 36.4 秒音频（16 小节 @105.47 BPM），音频验收通过后再做画面。**
2. 人声用「字块重复」：每个字 4 个 16 分触发，关键重拍用 32 分加花。
3. 伴奏用 Cm–B♭–F–Gm 循环，鼓组铺 16 分，drop 前留 1–2 小节静音。
4. 画面按段落的「镜头密度曲线」填，不按叙事剪。
5. 字幕一句一块，2 小节一块（短版），与镜头切点同步。
6. 母带 −10 LUFS，真峰 ≤ −0.5 dBTP。

### 8.2 曲式表（16 小节 / 36.4 秒）

| 小节 | 时间 | 段落 | 人声 | 鼓组 | 镜头密度 | 字幕 |
|---|---|---|---|---|---|---|
| 0–1 | 0–4.55 s | Intro | 「改革春风」4 字，8 分/16 分稀疏 | 只留 hats，第 2 小节进 kick | 低（2–3 个镜头） | 无/半句 |
| 2–3 | 4.55–9.10 s | Pre-drop | 「改革春风」加速到 32 分，重复 | 全鼓，第 3 小节末静音 1 拍 | 中（1 个长镜头 + 闪白） | 半句 |
| 4–5 | 9.10–13.65 s | Hook 1 | 「改革春风吹满地」7 字 ×4 个 16 分 | 全开 | 中（5 个镜头：3+2） | 整句 |
| 6–7 | 13.65–18.20 s | Hook 2 | 同句，尾字拖长/降调 | 全开 + 加花 | 中（4 个：3+1） | 整句 |
| 8–9 | 18.20–22.75 s | Verse 1 | 「中国人民真争气」 | 全开 | 中高（6 个：4+2） | 整句 |
| 10–11 | 22.75–27.30 s | Verse 2 | 「齐心协力跨世纪」 | 全开 | 中（3 个：2+1） | 整句 |
| 12–13 | 27.30–31.85 s | Verse 3 | 「一场大水没咋地」 | 全开 | 中高（5 个：3+2） | 整句 |
| 14 | 31.85–34.12 s | Hook 短句 | 「改革春风」重复 | 全开 | 高（4 个 / 1 小节） | 半句 |
| 15 | 34.12–36.40 s | Outro | 「吹满地」重复 + 低通 | 逐拍抽掉 | 低（2 个） | 整句 → 淡出 |

### 8.3 人声编排规则

**素材**：`demo/guichu-song/song-vocals-autotuned.wav`（或 `song-vocals-smooth.wav`）里已有 6 句、每句 7 字。先用静音切出 6 句，再用起音切出每句的 7 个字，建立一个 42 个音节的库。

**每个字的处理**：

1. 取该字最强的一段 60–120 ms（从起音开始）。
2. 用 WORLD 分析（F0 + 频谱包络 + 非周期成分）。
3. 按目标音高重合成：`f0_target = 目标音高 × (原 f0 / 原中位 f0)^0.3`，保留 30% 原始音高偏移，不要拉平。
4. 每个字生成 4 个短触发（每个 70–90 ms），落在连续的 16 分格上；重拍字用 32 分再切一刀。
5. 字与字之间留 10–20 ms 静音，制造辅音感。

**目标旋律**（C 小调，MIDI 音高）：

```
改(G4) 革(G4) 春(G4) 风(G4) | 吹(E♭4) 满(F4) 地(G4)  [空 1 拍]
```

其余句子同法，句尾落在 G4。Hook 重复时只换画面，不换音高。

**混音**：

- 高通 120 Hz。
- 压缩 4:1，attack 5 ms，release 60 ms。
- 叠一层 1/16 延迟（音量 0.25）和一层 +12 半音（音量 0.12，只在高潮段）。
- plate 混响 0.8 s，湿声 12%。
- 人声总线限幅，峰值 −1 dB。

### 8.4 编曲规则

| 元素 | 规则 |
|---|---|
| 和弦 | 每 2 小节：Cm → B♭ → F → Gm，然后循环 |
| 贝斯 | 8 分音符根音，第 3 拍加八度跳 |
| 底鼓 | 1、3 拍必打；第 2、4 拍加 syncopation；每 4 小节一个过门 |
| 军鼓 | 2、4 拍；hook 段加 16 分 ghost note |
| Hats | 每个 16 分都打，重音在 1、3、5、7、9、11、13、15 |
| 和弦 stab | 反拍（8 分后半）短促，音量 0.35 |
| Riser | 第 2–3 小节白噪声上扫 |
| Drop | 第 4 小节第 1 拍：全鼓 + 低音 + 人声同时进 |
| Outro | 第 15 小节低通从 8 kHz 扫到 1 kHz，最后 1 拍静音 |

### 8.5 混音链

```
人声 → HPF 120 → 压缩 4:1 → EQ +3 dB @3k → 叠层 → 混响 12%
伴奏 → 侧链（人声 −3 dB）→ 总线
总线 → 压缩 2:1 → 限幅 −0.5 dBTP → 目标 −10 LUFS
```

参考片是 −9.4 LUFS，我们做 −10 ± 1，不要超过 −9，否则会糊。

### 8.6 画面规则

**素材库**（全部来自 `zuotian.mp4`，17 分钟）：

| 类型 | 代表性 sourceStart | 用途 |
|---|---|---|
| 舞台大全 | 40 s、180 s、430 s | 段落开场、Outro |
| 双人中景 | 100 s、350 s、620 s | 主叙事 |
| 单人特写 | 720 s、830 s | 金句重音 |
| 观众席 | 260 s、520 s、930 s | 亮色 cutaway、节奏填充 |

**切点规则**：

- 所有切点吸附到 16 分网格。
- 主体的镜头长度是 4 拍（1 小节 / 2.27 s）；快段用 2 拍与 1 拍交替，禁止连续 3 个镜头同长度。
- 每个 2 小节块里，镜头数控制在 3–6 个；整片 34 个镜头、56 切/分钟，落在参考 A 段的 63.8/分钟附近。
- 每 4 小节至少一次「景别跳变」：大全 → 特写，或中景 → 观众席。
- 素材去重：先对 17 分钟素材做场景检测（scene ≥ 0.30，得到 85 个场景），按 WIDE / MED / CU 分类，逐个消费，**同一场景不重复使用**。
- 用 1.0 / 1.06 / 1.08 / 1.12 四档放大 + 负偏移，制造「假机位」。

**段落密度曲线**（与参考一致，按 2 小节块）：

```
Intro 2 → Pre-drop 3 → Hook1 5 → Hook2 4 → Verse1 6 → Verse2 3 → Verse3 5 → Hook短 4 → Outro 2 = 34 个镜头
```

**闪白**：第 4 小节第 1 拍、第 14 小节第 1 拍各加 2 帧白色（opacity 0.7）。

### 8.7 字幕规则

- 白色粗体 + 黑描边 5 px，底部居中，基线 88%。
- 字号 58–64 px（960×720 输出）。
- 一句一块：Hook/Verse 每 2 小节换一次；Outro 最后一块淡出。
- 字幕变化必须与某个切点同帧（±1 帧）。
- 不做逐字卡拉 OK；参考片是整句停留。

## 11. v2 实做记录

### 11.1 交付物

- 成片：[guichu-v2.mp4](../demo/guichu-v2/guichu-v2.mp4)，960×720 / 30 fps / 36.41 s / 11.1 MB。
- 音频母带：`demo/guichu-v2/assets/audio.wav`（−10.5 LUFS / −1.2 dBTP），成片内降到 0.88 增益给 AAC 留头。
- 工程：`demo/guichu-v2/project.json`（v1 分镜 34、v2 特效 9、v3 字幕 8、a1 音频 1）。
- 生成脚本：`demo/guichu-v2/tools/build_audio.py`、`tools/make_project.py`。

### 11.2 素材处理

1. 对 `zuotian.mp4` 做 scene 检测（阈值 0.30），得到 **85 个场景**。
2. 每个场景取首帧算亮度 / 饱和度 / 边缘密度 / 肤色比例，分为 WIDE 33、MED 39、CU 13。
3. 按段落密度表逐镜消费，**34 个镜头来自 34 个不同场景**，无重复素材。
4. 每个镜头先单独切出来（`assets/shots/shotNN.mp4`），再进合成。

### 11.3 渲染时踩到的坑

把 17 分钟的原片直接喂给 34–54 条 `trim` 分支时，ffmpeg 会为每条分支各缓存一帧，内存线性涨到 4 GB 后被 OOM kill
（`FFMPEG_PROGRESS_INVALID: stream ended without progress=end`，进度停在 15.3%）。

修法：**先按镜头预切**，让每条渲染分支只读一个 0.3–2.3 s 的小文件，内存峰值从 >4 GB 降到 <1 GB，34 秒渲染完成。

这件事本身也印证了「音频优先」的流程：声音先定，镜头长度就是音频块的长度，预切只是执行细节。

### 11.4 与参考的差距（下一版可继续做）

- 素材只有一台晚会，景别/机位丰富度不如参考；观众席与沙发镜头仍占多数。
- 响度 −11.8 LUFS，比参考轻 2.4 dB，可以再压 1–1.5 dB。
- 字幕是整句静态块，参考有少量逐字强调，可选择性加 2–3 处。

## 12. 一句话总结

参考片的「节奏感」不是某个调音参数，而是四个东西叠在一起：

**105.47 BPM 的硬网格 + 每字 4 次 16 分重击的人声 + 快慢交替的镜头密度 + −9.4 LUFS 的母带。**

我们上一版只做到了「切点对齐」，没做到「字块重复」「密度编排」「母带响度」。新版按第 8 节的顺序做：先出 36.4 秒音频，听完验收，再填画面。
