## v2 优化记录（工具和成片一起改）

v1 的问题：响度只有 -16.4 LUFS、字幕入点是手工估的、缺音效层、BGM 全程一个音量、9 个镜头平均 3.3 秒偏慢、9 个素材色温不统一。

### 一、工具新增三项能力

**1. 片段调色 `grade`**

```json
{ "type": "setClipParams", "clipId": "s1",
  "params": { "grade": { "warmth": 0.35, "contrast": 1.06, "saturation": 1.12 } } }
```

滤镜顺序固定在 `crop → grade → format → scale`：先裁再调色，避免放大后调色放大噪点。`warmth` 走 `colorbalance` 的 midtones 红/蓝偏移，其余走 `eq`。

**2. 音量曲线 `volumePoints`**

```json
{ "type": "setClipParams", "clipId": "bed",
  "params": { "volumePoints": [{ "at": 0, "volume": 0 }, { "at": 1.5, "volume": 0.16 }, { "at": 10, "volume": 0.24 }, { "at": 30, "volume": 0 }] } }
```

编译成 `volume=eval=frame:volume='if(lt(t,1.5),...,...)'` 的分段线性表达式，`at` 用片段内相对秒，曲线外自动保持首尾值。设了它就忽略 `volume`。

**3. 整片响度归一 `output.loudness`**

```json
{ "output": { "loudness": { "target": -14, "truePeak": -1.5, "range": 11 } } }
```

在 `amix` 之后、`atrim` 之前插 `loudnorm`，后面补 `aresample=48000`（loudnorm 内部会升到 192k）。单遍处理，适合 30 秒级的成片。

### 二、成片改了八处

| 维度 | v1 | v2 |
|---|---|---|
| 镜头数 / 平均时长 | 9 个 / 3.3s | 13 个 / 2.3s，前 10 秒 4 切 |
| 插入镜头 | 无 | 2 个特写（落叶、咖啡豆） |
| 调色 | 无 | warmth 0.35 / contrast 1.06 / saturation 1.12 |
| 音频层数 | 2（人声 + BGM） | 3（人声 + BGM + 3 个环境音效） |
| BGM 音量 | 恒定 0.22 | volumePoints 曲线：0→0.16→0.24→0.20→0.14→0 |
| 音效 | 无 | 雨（2.4s）、脚步（4.8s）、倒茶（13.2s），间隔 ≥2s |
| 字幕入点 | 手工估（最早一条早 0.5s） | 按语音边界：1.20 / 5.75 / 11.20 / 16.05 / 22.35 |
| 响度 | -16.4 LUFS | -14.0 LUFS / TP -1.5 dBFS |

### 三、两个测量上的坑

1. **ebur128 的 `I:` 不能取第一个**：日志里每一帧进度都带 `I:`，开头是静音所以是 -70。要取**最后一个**匹配值才是整片积分响度。我第一次取第一个，误判成"音频全静音"。
2. **选音效不用试听**：用 `highpass=f=3000` 和 `lowpass=f=300` 分别测 `mean_volume`，高频主导的是雨声/倒水，低频主导的是脚步。三个候选一次选中，省掉听音环节。验证也同理：对比各段高频能量，倒茶段比纯人声段高 9.6 dB，说明音效确实进了混音。

### 四、验收结果

- `30.000s / 1920×1080 / 30fps / H.264 + AAC / 39.8MB`
- `-14.0 LUFS`，真峰值 `-1.5 dBFS`
- 2s / 12s / 17s / 27s 四帧抽检：字幕居底部居中、无遮挡，画面色调统一
- 封面：0.5s 窗边剪影、27.5s 秋日湖面，均未带字幕，可直接裁 9:16
