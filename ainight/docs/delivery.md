天亮了，我还是打开了编辑器。

我不甘心。为什么不是我。

## 制作信息

- 规格：1920×1080 / 16:9 / 30fps / 14.96 秒 / 449 帧
- 音频：《一笑江湖》闻人听書_，1:04.53–1:19.49
- 歌词：这成败 有谁来了解 / 江湖一笑 浪滔滔 / 红尘尽忘了 / 俱往矣 何足言道
- 素材：4 张 AI 实景 + 3 张人物一致性重制（手部、过肩、背影）+ Pillow 程序化 UI 页
- 人物一致性：开场只露一次脸，之后全部用黑卫衣剪影、过肩和手部特写，避免 AI 换脸
- 渲染：Pillow + numpy + scipy；ffmpeg H.264 CRF22 + AAC192 + faststart；6 进程并行
- 代码：ainight/build/render.py、ainight/build/encode.sh
- 配置：ainight/config/timeline.json、ainight/config/lyrics.json
