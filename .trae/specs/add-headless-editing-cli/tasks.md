# Task Dependencies

- Task 1 是所有任务的前置。
- Task 2、Task 3、Task 4 可在 Task 1 后并行；Task 4 与 Task 3 集成时以统一写操作接口为准。
- Task 5 依赖 Task 2 和 Task 3；Task 6 依赖 Task 5。
- Task 7 依赖 Task 2 至 Task 6 的集成功能；各模块可先完成自己的局部测试。
- Task 8 依赖 Task 7，任何失败检查项都必须先修复再复验。
