## 旁白与字幕

- [x] 旁白为中文，语速 0.92–0.96，断句自然；多音字“二维/折返/高程”读音正确。
- [x] 旁白与字幕逐句一致；字幕入点与语音误差 ≤ 100ms。
- [x] 字幕最多 2 行、左右 ≥ 8% 安全区、底部 ≥ 96px；在亮地形上有 scrim，仍可读。
- [x] 字幕未遮挡站名、关键数字、URL；关键词强调不超过每句 1 个。

## 声音

- [x] BGM 在旁白下压低 14–16dB，无抢人声、无明显 pumping。
- [x] 音效峰值不盖过旁白；片头/片尾无爆音、无突然截断。
- [x] 整片 -14 LUFS ±0.5，真峰值 ≤ -1.5 dBFS。
- [x] 音频 48kHz 立体声，左右声道无异常偏移；静音段无底噪突变。
- [x] 结尾音乐自然收束，最后 1 秒黑场不突兀。
