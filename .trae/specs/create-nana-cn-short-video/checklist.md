# Checklist

- [x] 用户已确认创意、分镜、旁白和标题；未确认前没有开始制作。
- [x] 旁白音色、语气和开场形式已确认。
- [x] BGM 方案已确认（原创同类型，或用户提供原音频并授权）。
- [x] BGM 为 128 BPM、35.0s，包含两段 drop、808、军鼓滚奏和结尾收束。
- [x] `beatmap.json` 的小节线、drop 和音效点与分镜表一致。
- [x] BGM 全部为程序化合成或已授权素材，无未授权采样。
- [x] A 段育婴房、摇篮、床铃关键帧风格统一。
- [x] B 段客厅、奶奶多表情、时钟/路由器/手机/拖鞋道具风格统一。
- [x] 中文旁白 6 句齐全，语速和语气符合要求，人声清晰。
- [x] 画面切点落在 beat map 上，误差 ≤ 1 帧。
- [x] 花字和字幕中文无错字、无缺字、无遮挡。
- [x] 成片为 1080×1920、30fps、H.264/AAC、`+faststart`，时长 35.0s ± 0.1s。
- [x] 响度 -14 LUFS ± 1，真峰值 ≤ -1 dBTP。
- [x] 封面、联系表、脚本 JSON、beat map 和成片均已交付并可重新渲染。
- [x] 发布文案标注“AI 生成画面 / 原创音乐”，无版权风险。
