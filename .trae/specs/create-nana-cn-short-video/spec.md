# nana 中文强节奏竖屏短片 Spec

## Why

参考视频是一支 35 秒竖屏：Gemini 界面 + AI 生成的西语「nana」动效，BGM 节奏很强。用户想要同类型、但内容是中文的短片，并明确要求：**先把稿子写出来，确认后再制作**。

## What Changes

- 新增一支 35.0 秒、1080×1920、30fps 的中文竖屏短片《同一个 nana，两种命》。
- 新增原创 128 BPM 电子 BGM（不是原曲复刻）与逐拍 beat map。
- 新增中文分镜脚本、旁白、字幕和花字。
- 新增 AI 关键帧 + 程序化 2.5D 动效的视觉生产流程。
- 新增成片、封面、联系表、脚本 JSON 与 beat map 等交付物。
- **不**修改现有 `scripts/`、`v4/`、`travel/`、`codecut/` 的行为。

## Impact

- Affected specs：新增短视频脚本、原创音乐、AI 视觉、卡点剪辑、成片交付。
- Affected code：新增 `nana/`（`config/`、`build/`、`assets/`、`out/`）。
- Existing code：保持 v1 / v4 / travel / codecut 原样。
- Runtime：Python 3 + Pillow / numpy / scipy、ffmpeg、Noto Sans CJK / 得意黑；可选 GenerateImage / GenerateVideo。

## 先回答：BGM 能不能复刻？

**不能 1:1 复刻原曲，但能复刻“节奏强度”。**

| 方式 | 能做到什么 | 限制 |
| --- | --- | --- |
| 原创同类型 BGM（推荐） | 128 BPM、四拍底鼓 + 808、两段 drop、8 分音符快切，听感同样是“强节奏电子” | 不是原曲，音色达不到商业混音水准 |
| 使用用户提供的原音频 | 节奏 100% 一致，直接按原曲卡点 | 需要用户提供音频文件，并确认有权使用 |
| 从原视频提取音频 | 可得到原声，但需要原视频文件 | 用户已明确不需要原片；原音频版权归 @葡萄桃 |

本 spec 默认走**原创同类型 BGM**，并在成片和发布文案里标注“原创音乐”。

## 创意稿（请重点确认）

### 一句话概念

西语的 **nana** 是摇篮曲，哄你睡；中文的 **nana** 听起来像 **奶奶**，催你睡。同一个发音，两种命运。

### 标题与发布文案

- 视频标题：《中文会说吧？就是——奶奶。》
- 抖音文案：西语 nana，是摇篮曲；中文 nana，是奶奶。一个哄你睡，一个催你睡。#中文 #AI动画 #原创音乐 #奶奶
- 封面：左边粉色育婴房 + “nana”，右边中式客厅 + “奶奶”，中间大字「两种命」。

### 旁白（中文女声，俏皮）

1. 西语 nana，是摇篮曲。
2. 中文 nana，是——奶奶。
3. 一个哄你睡。
4. 一个催你睡。
5. 同一个 nana，两种命。
6. 晚安，做个好梦。

### 视觉风格

- **A 段（0–16.875s）**：Pixar 风 3D 育婴房，薰衣草粉 + 月光 + 星尘 + 柔光；镜头缓慢推近，2.5D 视差。
- **B 段（16.875–35s）**：中式客厅，冷白灯 + 电视蓝光 + 花睡衣奶奶 + 拖鞋 + 暖水瓶；手持感、快推、甩镜。
- **字体**：A 段柔和圆体/衬线；B 段 Noto Sans CJK Black 或得意黑，红白贴纸字。
- **转场**：beat 点硬切、白闪、0.2s 黑场、glitch（RGB 分离 + 扫描线）。

### 声音设计

- **BGM**：128 BPM，A 小调，35.0s，全部程序化合成（无采样）。
  - 0–3.75s：滤波 pluck + 键盘声 + 反向 riser。
  - 3.75–16.875s：四拍底鼓 + 柔和 sub + 竖琴 pluck + 女声和声切片；第 9 小节军鼓滚奏。
  - 16.875s：0.2s 静音 + 心跳 + impact，进入 trap drop。
  - 16.875–31.875s：trap 鼓组 + 808 滑音 + 快速 hat + glitch。
  - 31.875–35.0s：鼓组退出，钢琴单音 + 风声 + 低频收尾。
- **旁白**：中文女声 TTS，语速偏快；按分镜时间放置，BGM 侧链避让。
- **音效**：键盘、开关灯、拖鞋、电视噪声、心跳、whoosh。
- **响度**：-14 LUFS，真峰值 ≤ -1 dBTP。

### 制作路线

1. 脚本/分镜确认（本 spec）。
2. 用 AI 生成关键帧：育婴房、摇篮、奶奶（多表情）、客厅、时钟、路由器、手机、拖鞋；统一 Pixar 3D 风格。
3. 用 Python（Pillow + numpy）做 2.5D 视差、粒子、文字动效、glitch；可选 GenerateVideo 生成 2–3 个 hero 镜头。
4. 合成原创 BGM 与 TTS 旁白，输出 beat map。
5. 用 ffmpeg 按 beat map 剪辑、叠字幕/花字、调色、混音。
6. QA：ffprobe、抽帧、响度、文字校对、卡点误差 ≤ 1 帧。

## ADDED Requirements

### Requirement: 脚本先审后做

在用户明确确认分镜、旁白和标题之前，系统 SHALL NOT 生成 BGM、视觉素材或成片。

#### Scenario: 用户确认脚本

- **WHEN** 用户确认本 spec 中的创意、分镜和旁白
- **THEN** 才开始 Task 2 及之后的制作

#### Scenario: 用户要求修改

- **WHEN** 用户修改创意、台词或时间点
- **THEN** 先更新本 spec 和分镜表，再次确认后才继续

### Requirement: 原创强节奏 BGM

系统 SHALL 生成 128 BPM、35.0s 的原创 BGM，包含两段 drop、808 贝斯、四拍底鼓、军鼓滚奏、riser、impact，并输出与分镜对齐的 beat map。BGM SHALL 不包含任何未授权采样。

#### Scenario: BGM 与分镜对齐

- **WHEN** 读取 `beatmap.json` 与分镜表
- **THEN** 每个段落起点都落在对应小节线上，误差 ≤ 1 帧

#### Scenario: 用户提供原音频

- **WHEN** 用户提供原音频并确认有权使用
- **THEN** 用原音频替换原创 BGM，重新按原曲卡点，其余流程不变

### Requirement: 中文竖屏成片

系统 SHALL 输出 1080×1920、30fps、H.264/AAC、约 35.0s 的 MP4，画面包含 A/B 两段场景、中文花字、旁白和音效。

#### Scenario: 成片可播放

- **WHEN** 用 ffprobe 检查输出
- **THEN** 分辨率、帧率、时长、编码符合要求，完整解码无错误

#### Scenario: 中文文字正确

- **WHEN** 抽查每一句花字和字幕
- **THEN** 无错别字、无缺字（豆腐块）、无遮挡关键画面

### Requirement: 卡点剪辑

剪辑 SHALL 以 beat map 为准：段落切换落小节线，蒙太奇快切落 8 分音符；画面动作（转头、关灯、甩镜）SHALL 与鼓点或音效对齐。

#### Scenario: 卡点误差

- **WHEN** 对比成片切点与 beat map
- **THEN** 误差 ≤ 1 帧（33ms）

### Requirement: 交付与可复现

系统 SHALL 交付成片、封面、联系表、脚本 JSON 和 beat map，并保留可重跑的构建脚本。

#### Scenario: 重新渲染

- **WHEN** 运行构建脚本
- **THEN** 能从素材和配置重新生成同一支成片
