## 2. 技术边界与对策

| 边界 | 影响 | 对策 |
|-|-|-|
| 生成工具时长只能 4–15 秒整数 | 1 秒镜头无法直接生成 | 生成 ≥4 秒再按帧裁切，切点由 ffmpeg 锁定 |
| 生成工具不能输入音频 | 无法让模型跟着原声走 | 画面只做动作与口型，音轨后期对齐 |
| 单次最高 720p | 达不到 1080p 原生 | 先出 720×1280，必要时 lanczos 升 1080×1920 |
| 单轮生成次数有限 | 不能一次出完 | 按 3–4 轮排期，每轮只提 1–3 条 |
| 无专用口型模型 | 只能词首开合 | 已在方案内接受；提示词限制嘴部幅度 |
| 长片段易漂移 | 角色跑形 | 主舞单条不超过 7 秒；每条都挂基准三视图 |

## 3. 阶段 A：额度与一致性冒烟测试（1 次生成）

- 输入：`refs/idle.png` 作为 `<图片1>`
- 参数：9:16、720p、4 秒、单镜头
- 验收：
  1. 能正常出片（额度可用）
  2. 狐耳、琥珀眼、额间金纹、九尾扇形轮廓、纱裙结构不变
  3. 无转圈/跳跃/多尾/断肢
- 不通过则先不铺样片：优先修参考图或改提示词，再重测 1 条。

## 4. 阶段 B：5 秒样片（2 次生成 → 1 条成片）

### 4.1 关键改进

原 `shots.json` 规划 4 个镜头各生成 1 条，受 1 秒限制必须生成 4 秒再裁，且四条独立生成最容易角色漂移。
改为**两条生成**：

- **主舞条（6 秒）**：待机帧生成，覆盖 Shot 1、3、4（需覆盖到 5.16s，故生成 6 秒而非 5 秒）
- **凑近条（4 秒）**：凑近帧生成，替换 1.000–2.000s 窗口，压在 `right` 词首 1.400s

这样额度省一半，且 Shot 1→3→4 的画面来自同一条连续素材，动作不跳。

### 4.2 样片时间线

| 段 | 区间(s) | 画面来源 | 动作要点 | 音频触发 |
|-|-|-|-|-|
| S1 | 0.000–1.000 | 主舞条 0.0–1.0 | 居中待机舞步、轻摆 | Sp/ider/is/easy 词首 |
| S2 | 1.000–2.000 | 凑近条 0.0–1.0 | 瞳孔放大、上身凑近、尾巴后拉 | right 词首 1.400 |
| S3 | 2.000–3.158 | 主舞条 2.0–3.158 | 恢复构图、换手势、闭口 | 停顿 1.54–3.10 |
| S4 | 3.158–5.160 | 主舞条 3.158–5.160 | 继续舞步、词首轻开合 | How…Spanish 词首 |

### 4.3 合成命令（样例，执行时按实际路径）

```bash
# 1) 统一规格：720×1280 / 30fps / 无音轨
ffmpeg -y -i gen/main_idle.mp4 -an \
  -vf "scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280,fps=30,setsar=1" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p gen/n_main.mp4

# 2) 逐段裁切
ffmpeg -y -i gen/n_main.mp4 -ss 0 -t 1.000 -c:v libx264 -crf 18 seg_1.mp4
ffmpeg -y -i gen/n_close.mp4 -ss 0 -t 1.000 -c:v libx264 -crf 18 seg_2.mp4
ffmpeg -y -i gen/n_main.mp4 -ss 2.000 -t 1.158 -c:v libx264 -crf 18 seg_3.mp4
ffmpeg -y -i gen/n_main.mp4 -ss 3.158 -t 2.002 -c:v libx264 -crf 18 seg_4.mp4

# 3) 拼接（concat demuxer，list 内写 seg_1..4）
ffmpeg -y -f concat -safe 0 -i seglist.txt -c copy gen/video_silent.mp4

# 4) 贴原声并导出
ffmpeg -y -ss 0 -t 5.16 -i source-audio.mp3 -i gen/video_silent.mp4 \
  -map 1:v -map 0:a -c:v libx264 -crf 18 -c:a aac -b:a 192k \
  -shortest -movflags +faststart out/sample_5s.mp4
```

产出：`beat-fox/out/sample_5s.mp4`（约 5.16s）、`beat-fox/qa/sample_frames/` 抽帧对照。

## 6. 提示词模板

统一固定块（每条都带，且 `<图片1>` 固定为角色帧）：

> 角色严格参考 `<图片1>`：白狐首，竖立狐耳、耳内浅橘，小巧狐吻，琥珀色兽眼，额间细金纹；脸、胸、腹、爪为白色，耳背、脊背与九尾外层为淡金橘渐变、尾尖淡金；九尾呈装饰性扇形展开；修长少女体型、窄肩细腰、四肢小巧；月白薄纱仙裙、浅青透明纱袖、腰侧飘带；浅雾青薄雾背景，柔和动漫渐变光。禁止改变毛色分区、尾巴数量与服装结构。

**主舞条**（M1–M6 共用，只改手势/幅度描述）：

> 竖屏 9:16 单镜头，中景全身。{固定块}。动作：角色位于画面中央做轻缓待机舞步，身体随节拍左右轻摆，纱袖、裙摆与九尾同步做柔软滞后摆动；嘴部只做词首级别的轻微开合，词中收小，不做大嘴型。镜头：固定机位，仅保留极轻微呼吸感。风格：唯美国风动漫插画、柔和体积光。约束：不新增转圈、跳跃、大甩尾；尾巴始终九条且轮廓稳定；不切镜、无文字、无字幕、无水印。

**凑近条**（R1–R3）：

> 竖屏 9:16 单镜头，中近景。{固定块}。动作：由静止起，琥珀色瞳孔轻微放大，上身向前凑近镜头半步，九尾与轻纱因动势向后拉开，随后眼神定住约 0.1 秒；嘴部几乎闭合，只在词首有极小开合。镜头：唯一一次轻微推近。风格同上。约束：不张嘴大吼、不新增尾巴、不切镜、无文字水印。

变体只改一句动作幅度，例如 M2 用“换一套更小的手势、肩线轻微侧转”，M6 用“舞步收束、身体微沉”。所有条目沿用同一固定块，避免每镜重写外观。

## 7. 质检清单

合成前后各跑一遍：

- [ ] 角色：狐耳、琥珀眼、额间金纹、毛色分区、九尾轮廓、纱裙飘带一致
- [ ] 尾巴数量全程九条，无新增/减少/分叉
- [ ] 无多余大动作（转圈、跳跃、甩尾），单镜一个主动作
- [ ] 切点：样片 1.000 / 2.000 / 3.158；整片压 right、España、Tomorrow 词首
- [ ] 嘴部只有词首开合，无夸张大嘴
- [ ] 音画同步偏差 < 1 帧（30fps 下 33ms）
- [ ] 规格：720×1280（或 1080×1920）、30fps、H.264 + AAC、faststart
- [ ] 竖屏安全区：底部约 250px（1080×1920 基准）、顶部约 120px 不放关键信息

## 9. 风险与兜底

| 风险 | 触发信号 | 兜底 |
|-|-|-|
| 生成额度不足 | 工具提示次数上限 | 走仓库既有 `v4/build` 截帧链路：Canvas/HTML 占位角色 → Chromium 截帧 → ffmpeg 合成，先出节奏版 |
| 角色漂移 | 毛色/尾数/服装变化 | 每条挂基准三视图；缩短单条时长；必要时用基准图重生成派生帧 |
| 动作过大 | 出现转圈、跳跃 | 提示词加禁止项，单条只描述一个主动作 |
| 口型违和 | 张嘴过大或不同步 | 收小提示词幅度；必要时闭口版重生成 |
| 版权 | 原声/台词被识别 | 样片仅内部核对；发布前换可商用 BGM 与合规人声，重对卡点 |
| 归档链接失效 | CDN 404（已发生） | 统一改用飞书文件 token，文档 3.1/3.2 表格替换失效链接 |
